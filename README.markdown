# Alt Mobility Analysis Report - README

## Overview
This project analyzes customer, order, and payment data for Alt Mobility to uncover insights into sales performance, customer behavior, and operational efficiency. The analysis leverages SQL queries to extract meaningful trends and provides actionable recommendations to improve business outcomes.

## Purpose
The goal of this report is to:
- Summarize key findings from order, payment, and customer data.
- Analyze customer retention trends using cohort analysis.
- Provide data-driven recommendations to enhance fulfillment, payment processes, and customer retention strategies.

## Data Sources
The analysis is based on the following datasets:
- **Order Data:** Includes order IDs, customer IDs, order dates, amounts, statuses, and payment details.
- **Payment Data:** Covers payment methods, statuses (completed, failed, pending), and amounts.
- **Customer Data:** Contains customer IDs, order frequencies, and cohort months for retention analysis.
- **Revenue Data:** Monthly revenue figures from 2020-01 to 2021-02.
