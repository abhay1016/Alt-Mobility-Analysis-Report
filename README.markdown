# Alt Mobility Analysis Report - README

## Overview
This project analyzes customer, order, and payment data for Alt Mobility to uncover insights into sales performance, customer behavior, and operational efficiency. The analysis leverages SQL queries to extract meaningful trends and provides actionable recommendations to improve business outcomes.

## Purpose
The goal of this report is to:
- Summarize key findings from order, payment, and customer data.
- Analyze customer retention trends using cohort analysis.
- Provide data-driven recommendations to enhance fulfillment, payment processes, and customer retention strategies.

## Data Sources
The analysis is based on the following datasets:
- **Order Data:** Includes order IDs, customer IDs, order dates, amounts, statuses, and payment details.
- **Payment Data:** Covers payment methods, statuses (completed, failed, pending), and amounts.
- **Customer Data:** Contains customer IDs, order frequencies, and cohort months for retention analysis.
- **Revenue Data:** Monthly revenue figures from 2020-01 to 2021-02.

## Key Findings
- **Order and Sales:** 5,057 orders are delivered, but 5,069 remain pending, indicating fulfillment bottlenecks. Peak revenue months are 2020-12 ($23,076.31) and 2020-05 ($22,535.61).
- **Customer Behavior:** Returning customers (4,402) outnumber first-time buyers (2,932), with high repeat rates (e.g., customer 5557 with 7 orders).
- **Payment Trends:** 5,003 payments failed, with bank transfers (1,758) and credit cards (1,666) showing the highest failure rates.
- **Retention Trends:** Early cohorts show stronger retention, while newer ones drop off sharply, highlighting the need for post-purchase engagement.

## Recommendations
- **Streamline Fulfillment:** Automate follow-ups for the 5,069 pending orders to reduce delays.
- **Target High-Value Customers:** Launch a "premium customer" program for orders above $292.
- **Optimize Payments:** Investigate and address the 5,003 failed payments, focusing on bank transfers.
- **Boost Retention:** Implement loyalty programs and re-engagement campaigns targeting drop-off months.
- **Seasonal Planning:** Align marketing and operations with peak months like 2020-12.
